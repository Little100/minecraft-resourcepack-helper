# MCRH (Minecraft Resourcepack Helper)

在 VS Code 中绘制贴图、预览模型与游戏界面，并管理 Minecraft Java 版资源包。

## 项目特点

- **像素绘制与动画**支持图层、选区、对称画笔、智能辅助线和参考图。可逐帧编辑动画，也可将 GIF 和 APNG 转成 Minecraft 动画贴图并生成 `.png.mcmeta`。
- **3D 模型与 GUI / HUD 预览**可预览方块模型及物品的手持、掉落与物品栏效果，也可查看快捷栏、容器和菜单贴图。模型可在 Blockbench 中打开。
- **资源编写与原版补全**提供方块状态、模型、音效、语言等模板，支持同类 JSON 批量套用、OptiFine 属性补全，以及按游戏版本补齐原版资源。
- **高级材质与场景**提供批量贴图处理、连接纹理 (CTM)、随机纹理、颜色图和 PBR 材质工具。可用图形化积木调整材质，在场景中查看光照效果。
- **资源包管理与诊断**支持多包合并、同路径文件冲突选择、版本转换和 ZIP 导出。可查看文件改动与转换限制，并检查资源引用和文件格式。
- **协作与审查**支持浏览 Git 变更和历史，并提供成员权限、提交审批和协作待办。
- **MCP 集成**让 MCP 客户端按工作区预览贴图、编辑像素和图层、修改模型 JSON，以及运行资源诊断。

扩展面板支持简体中文和英语。
